# Coartada 3D (exploración)

Versión 3D experimental de Coartada, con un solo caso: The Office · "Prison Mike".
El tablero es una maqueta en 3D (Three.js); la lógica y el caso son los mismos del juego original.

**Jugar:** https://matiasmunozb.github.io/coartada-3d/

Juego original: https://matiasmunozb.github.io/coartada/

Proyecto de fans, sin fines de lucro. Los personajes pertenecen a sus respectivos dueños.
